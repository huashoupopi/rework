# 风机叶片缺陷修复指南

## 1. 概述

风机叶片在长期运行中受到风载荷、雨蚀、紫外线和温度变化的影响，常见缺陷包括腐蚀、裂纹、隐裂、表面损伤和雷击损伤。本指南提供各类缺陷的现场修复规范。

---

## 2. 常见缺陷分类与判断标准

### 2.1 腐蚀（Corrosion）

- **特征**：叶片前缘或后缘出现材料剥落、坑蚀，表面粗糙度增大
- **严重等级**：
  - 轻度：面积 < 0.1 m²，深度 < 1 mm
  - 中度：面积 0.1~0.5 m²，深度 1~3 mm
  - 重度：面积 > 0.5 m² 或深度 > 3 mm，需停机修复

### 2.2 裂纹（Craze）

- **特征**：叶片表面或结构层出现可见线状裂缝
- **危险性**：裂纹若延伸至结构层（玻璃纤维/碳纤维），可能导致叶片断裂
- **判断方法**：目视检查 + 红外热成像 + 超声波检测

### 2.3 隐裂（Hide Craze）

- **特征**：表面无明显裂缝，但内部层间已分离
- **检测方法**：敲击法（空鼓音）、超声波扫描、热像仪
- **注意**：隐裂肉眼不可见，需依赖专业设备定期检测

### 2.4 雷击损伤（Thunderstrike）

- **特征**：叶尖或叶片中部出现烧蚀孔洞，导电条断裂，碳纤维层炭化
- **处理原则**：必须停机，评估叶片完整性，损伤面积 > 200 cm² 时建议更换叶片

### 2.5 表面油污（Surface Oil）

- **来源**：齿轮箱渗漏、液压油滴落
- **危害**：油污腐蚀涂层，并影响叶片气动性能

---

## 3. 修复流程

### 3.1 修复前准备

1. 停机并锁定叶轮（机械制动 + 变桨锁定）
2. 检查天气：风速 < 8 m/s，温度 5~35°C，相对湿度 < 80%
3. 安全防护：高处作业绳索系统，至少 2 人协作
4. 准备材料：环氧树脂、玻璃纤维布、砂纸（80/120/240 目）、丙酮清洗剂

### 3.2 腐蚀修复步骤

```
1. 用 80 目砂纸打磨腐蚀区域，去除松散材料
2. 丙酮清洗，待干燥（≥ 30 分钟）
3. 填充环氧腻子，刮平，固化 4 小时
4. 120 目砂纸打磨至平整
5. 涂刷底漆（干燥 2 小时）+ 面漆（前缘保护漆）
6. 240 目砂纸抛光，恢复气动轮廓
```

### 3.3 裂纹修复步骤

```
1. 沿裂纹两侧各 20 mm 范围打磨至玻璃纤维层
2. V 型开槽（槽深需超过裂纹深度 2 mm）
3. 丙酮清洗，吹干
4. 注入低黏度环氧树脂（真空注入效果更佳）
5. 铺 2~4 层玻璃纤维布（每层固化后再铺下一层）
6. 打磨至与原叶片轮廓一致
7. 涂层恢复
```

### 3.4 雷击损伤修复步骤

1. 拍照记录损伤范围，上报运维系统
2. 清除炭化材料至新鲜基材
3. 修复导雷系统（导电条更换或焊接）
4. 按裂纹修复流程修复结构层
5. 第三方检测认证后方可复役

---

## 4. 修复质量验收标准

| 检查项目 | 合格标准 |
|---|---|
| 表面平整度 | 与原叶片轮廓偏差 < 1 mm/m |
| 涂层附着力 | 划格测试 0 级（无脱落） |
| 修复区硬度 | 邵氏 D 硬度 ≥ 75 |
| 超声检测 | 无内部空洞或分层 |
| 导雷系统 | 接地电阻 < 10 Ω |

---

## 5. 修复后维护建议

- 修复后 72 小时内避免满发运行，观察振动数据
- 下次定检时重点检查修复区域边缘
- 建议每 6 个月对修复区域进行无损检测（NDT）
- 腐蚀严重区域建议加装前缘保护带（PU 保护膜）

---

## 6. 常见错误与注意事项

- **错误**：在湿润环境下施工 → 导致涂层起泡脱落
- **错误**：跳过底漆直接涂面漆 → 附着力不足
- **错误**：固化时间不足就打磨 → 材料损坏
- **注意**：环氧树脂混合比例必须严格按产品说明，误差 > 5% 将导致固化不完全
